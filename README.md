# APEX NOCTURNE

Jeu de course de rue nocturne en monde ouvert, jouable dans le navigateur — **100 % procédural**
(modèles 3D, ville, textures, sons et musique générés par le code, aucun asset externe).

Vite · React · TypeScript · Tailwind CSS · Three.js · Web Audio API.

```bash
npm install
npm run dev      # http://localhost:5173
```

- **Monde ouvert** : Port-Sélène de nuit — centre-ville néon, quartier Lanterne, docks, collines
  sinueuses, périphérique avec tunnel et pont, rampes de saut, trafic civil.
- **Épreuves** : sprint, circuit, drift, drag (boîte manuelle), radars.
- **Poursuites** : niveau d'alerte 1 à 5, intercepteurs, SUV, barrages, herses, hélicoptère,
  brise-poursuites destructibles.
- **Garage** : 7 voitures, tuning mécanique sur 4 niveaux, peinture, jantes, ailerons, kits, néons.

Contrôles, architecture et conventions : voir [CLAUDE.md](./CLAUDE.md).
